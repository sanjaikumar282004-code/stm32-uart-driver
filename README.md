# STM32 UART Driver

## Hardware
- STM32F401RE Nucleo Board

## Projects Included

### UART_TX
Transmit character using USART2.

### UART_MODULAR
UART driver using separate source and header files.

### UART_PRINTF
printf redirection using __io_putchar().

### UART_RX
Receive and echo characters through USART2.

### UART_LED_CONTROL
Control onboard LED using UART commands.

## Concepts Covered
- USART2
- Polling
- UART Transmission
- UART Reception
- Driver Abstraction
- printf Redirection
- Embedded C
- Register-Level Programming
